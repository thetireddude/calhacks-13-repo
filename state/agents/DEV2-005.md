### P2

1. **Persistence stub vs DEV2-003 schema**
   - **Area:** `apps/api/src/groups/store.ts`, production `createApp()` default
   - **Issue:** Group/invite/member state lives in `InMemoryGroupsStore` only; no Supabase client or RLS-backed reads/writes despite DEV2-003 migrations.
   - **Why it matters:** Restart loses data; parallel API instances diverge; Gate 1 stub is acceptable per task (“mock DB optional”) but integration spine needs an explicit follow-up task before mobile can rely on shared state.
   - **Smallest fix:** Track as next Dev 2 task (Supabase-backed `GroupsStore` implementation); no change required to merge this route/DTO slice.

2. **403 coverage in tests**
   - **Area:** `apps/api/src/groups.test.ts`
   - **Issue:** Non-member **403** is asserted only for `GET /v1/groups/:groupId`, not for `POST .../invites` or `GET .../members` (same `memberOnly` preHandler).
   - **Why it matters:** Acceptance criteria mention 403 “where applicable”; behavior is likely correct but not fully regression-locked.
   - **Smallest fix:** Add two inject cases with outsider JWT (mirror existing GET test).

3. **Group existence enumeration**
   - **Area:** `apps/api/src/groups/routes.ts` (`memberOnly`)
   - **Issue:** Authenticated non-members receive **403** when `groupId` exists and **404** when it does not, which can leak existence of UUIDs to any signed-in user.
   - **Why it matters:** Common IDOR hardening pattern is uniform 404 for non-members; SPEC/error schema not frozen yet.
   - **Smallest fix:** Defer until error contract ADR; or return 404 for both unknown group and non-member on member-scoped routes.

4. **Allowed-files surface**
   - **Area:** `state/CURRENT.md`, `tasks/DEV2-005-api-groups-invites.md` in commit
   - **Issue:** Task “Allowed files” lists only `apps/api/**` and `packages/contracts/**`; orchestration/state edits are outside that list.
   - **Why it matters:** Process hygiene for parallel lanes, not functional defect.
   - **Smallest fix:** Orchestrator-owned state updates on merge, or note in handoff.
